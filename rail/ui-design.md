# MAP33 · 界面与交互调整

只调整呈现、导航及页面组织。客流、满意度、班次、建设费用、贷款、成就和存档格式沿用MAP32；使用原动作处理器，没有增加另一套运营状态。

## 问题与处理

| 原问题 | 新安排 |
|---|---|
| 常用功能藏在管理菜单，散落的入口位置不固定 | 固定左侧任务导航：运营、客流、城市、财务、建设 |
| 余额、运行、客流多张卡片挤占地图 | 单一顶部状态栏：余额、今日完成出行、时钟、暂停与速度 |
| 线路详情是很长的表单 | 概况、车辆、车站、交路、设置五个标签；切换不重建表单，保留未应用值 |
| 同一线路在满意度列表和调度列表重复出现 | 合并为一张调度卡，评分放在卡片标题旁；全网评分保留概览 |
| 二级页面缺少明确归属 | 运营工作区含线路、候车、列车库、报警；客流含分时和分线；城市含总览与枢纽 |
| 找不到入口 | 查找功能支持名称和关键词；Ctrl/Cmd K、1–4和B快捷键 |
| 危险操作与普通操作并列 | 删除线路移到线路设置的折叠区，保留原二次确认；新游戏移至更多 |
| 文件选择时界面周期刷新可能替换input | 文件选择期间保留控件，选择或取消后恢复侧栏更新 |

财务、存档、成就、诊断、显示及性能设置仍可使用。原帮助气泡、引导关闭偏好、地图缩放分级、旁栏浏览继续保留。窄屏仍保留左侧导航和顶部状态，工作区覆盖地图的一部分，可关闭回地图；不改为全屏功能页。

## 借鉴

- [Mini Metro](https://dinopoloclub.com/games/mini-metro/)：地图优先的设计方向，减少常驻控件，不复制其游戏素材。
- [NIMBY Rails quickstart](https://wiki.nimbyrails.com/Quickstart_guide)：按任务区分轨道、线路、车辆编辑，以及可发现的导航和键盘操作。
- [Material navigation rail](https://m3.material.io/components/navigation-rail/overview)：常驻目标与当前目标的可见状态。

## 验证

桌面浏览器检查各主入口、运营/客流/城市子入口、查找跳转、线路五个标签、车站返回、未应用投放值在标签间保留、存档导入导出。390px嵌入视口检查常驻导航、子入口、隐藏菜单不遮挡。全部轨交回归套件通过；暂停状态下导航前后两次JSON导出，state与runtime逐字一致。未使用玩家真实大存档，本地QA使用三线十四站测试存档。
