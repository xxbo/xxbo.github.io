# MAP46：运营统计计算迁入Rust

## 剩余核心

详见[完整能力盘点](core-rust-inventory.md)。按12个能力域统计：5类此前已迁移主计算，本轮完成第6类的事件统计计算，另6类仍主要在JS。统计查询/日归档、旧模型兼容和跨模块的状态镜像仍有收尾任务。能力域数量用于规划，不代表代码量、内存或性能完成率。

本轮选择运营统计，是因为MAP45虽然已由Rust执行乘客事件，仍将每条事件和每段行驶逐一回传JS，再进行日/线/站/小时统计。满意度、财务、城市和主时钟的迁移留给后续阶段。

## 本轮实现

- 新增`statistics.rs`，在现有`simulation_step`中处理进站/上车/下车/拒乘/完成出行、分线票款、候车分钟、客运/车辆周转量与变动成本、分时曲线、滚动小时峰值及客流/周转纪录。
- 统计值在Rust中按原事件顺序累加，再回传字段最终值。既有浮点累计顺序、按线归属、重复线路ID语义、已购票价与存档字段顺序都保持一致。
- 热路径不额外调用第二个WASM函数，`queue-runtime.js`不再逐事件调用`Q.event/Q.travel`。
- 同一统计记录最多三个字段合并为一行；原生端给出小时窗口删除位置、尾项新增标志与最终值，替代每次完成出行都重传整段小时数组。
- 财务分摊暂在JS，按字段记录增量输入；满意度衰减每分钟使统计输入重同步。新日期、时段、档案/世界替换和实例恢复也会重新同步，避免覆盖已有结算。
- JS仍可直接调用统计API，但计算转交原生统计入口。结构编辑的成批拒乘合并为一个调用，避免删线时出现逐档案跨语言往返。
- `statistics-wasm.js`仅负责身份映射、数值编码和视图投影。日归档与实时查询仍在JS；本轮并未删除运行数据的JS镜像。
- 旧队列协议仍供冻结对照实现使用；新页面使用带统计输入的协议。老v1–v5二进制继续保留，新资源为`rail-core-v6.wasm?v=46`。

## 性能实测

各实现独立Node进程，使用相同需求与寻路内核；预热30个游戏分钟，测量5段各120个游戏分钟取中位数。MAP45对照为冻结的运行/统计接口，使用本轮内核保留的旧队列协议。脚本输出全部原始样本与完整状态校验和。

| 实现 | 10线25站：120游戏分钟 | 14线49站：120游戏分钟 |
| --- | ---: | ---: |
| MAP43 JS连续模拟 | 233.37ms | 464.93ms |
| MAP45 原生队列＋JS统计 | 283.87ms | 623.22ms |
| MAP46 原生队列＋统计 | 220.09ms | 477.32ms |

本轮相对MAP45耗时分别下降约22%和23%。与MAP43相比，小规模约快6%，14线约慢3%，因此仍应按场景验证。三组实现的完整计算结果在两个规模均完全一致；这不是浏览器FPS测量。

- 10线校验和：`7493d281e4759cf9dca15d98b3464fb31f4bdd1b0ad69b56748dd1999c58af55`。
- 14线校验和：`6b9c40a4f8096db0e414974d6d68db09d2f3fe9eefd4646c958958219cffa851`。

10线进程峰值RSS：MAP45 165.99MiB、MAP46 164.14MiB；14线分别315.86、315.91MiB。本轮尚未消除双份运行状态，内存仍在同一量级，OOM专项仍需继续减少双份状态与控制存档峰值。

独立带计数剖析的60个游戏分钟：

| 项目 | MAP45 | MAP46 |
| --- | ---: | ---: |
| 队列WASM批次 | 600 | 600 |
| 稳态队列全量重建 | 0 | 0 |
| 输入字节 | 3068376 | 3438792 |
| 输出字节 | 9084096 | 7375936 |
| 逐事件JS统计调用对应记录 | 48296 | 0 |
| 合并后的统计投影行 | — | 21606 |

输出字节下降约19%，输入因统计上下文同步略有增加。计数包装会影响时间，剖析计时不用于上表性能结论。

## 验证

- 45个回归套件，含原有1082个完整连续检查点、1196个抽样对照及MAP45拥挤、改签和实例回收测试。
- MAP46新增261组直接事件/周转对照与397个完整MAP45运行检查点，严格比较JSON字段顺序；涵盖分数客流、时段/日/小时边界、财务交错、外部统计、重算和强制恢复。
- 高负荷删除所有线路：所有受影响拒乘统计使用一次原生调用；热循环统计集成在原有批次，未新增独立调用。
- Rust合计12个单元测试，含字段插入顺序和缺失值语义；固定Rust工具链构建检查继续比较二进制字节。
- 12模拟小时、12次需求重算和12次存档往返：生成6168、完成6044，乘客守恒；采样JS堆峰值23.74MiB，进程RSS峰值254.18MiB。压力测试包含重算与存档，与纯模拟基准范围不同。
