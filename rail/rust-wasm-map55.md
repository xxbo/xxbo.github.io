# MAP55：P1 日归档与纪录规则

基线为已合入的 MAP54：`44985f2`。本批推进 P1-1 的归档、分时查询和纪录规则，不把统计历史全部驻留 Worker 或自主跨日计为已完成。

## 已迁移

新增 `history.rs` 与 `history_run` 数值 ABI，`history-wasm.js` 负责输入编码和原有 JSON/视图投影。

- 日归档：07:00 日号/边界、相邻日连续观测判断、上一日补齐规则、线路成熟度快照值及最近 30 日的裁剪位置由 Rust 返回。`ensureDay` 只在日号不一致时调用，常规每步路径不增加归档查询。归档保留旧日所有字段，跳日不虚构中间日。
- 分时查询：15/30/60 分钟合并、缺失与实际零值、部分窗口、总量及峰值判断迁入 Rust；并列峰值保留最早窗口。前端继续生成图表点对象，`peak` 引用对应点，不修改源历史。
- 纪录：线网轨道去重长度、分线长度与最长线路迁入 Rust，保持原遍历/浮点相加顺序；共享轨道不会重复计入线网长度。保留缺失轨道及重复标识的原有公共接口语义。
- 成就：个人与单局纪录的有限值归并、可选字段保留、成就阈值/容差、进度和人民币显示数值规则由 Rust 计算。名称、类别、模板、界面去重提示和存储留在 JS。
- 页面、需求 Worker、运营诊断 Worker 均加载新适配器，升级缓存参数与 WASM ABI 验证。模拟 Worker 继续使用同一 Rust 核心。

使用 `historyCalls` 单独记录这些查询，避免混入需求预测计数。版本化资源为 v15；v14 保留用于上版追溯。

## 验证

- 25 项 Rust 单元测试，新增日切/跳日/裁剪和可选纪录规则检查。
- `test_rail_map55_history.cjs`：3,953 次冻结 MAP54 JS 对照，逐字段并比较 JSON 字段顺序。覆盖相邻/跳过/回退日期、旧档缺失或异常流量字段、30 日历史、部分观测、峰值并列、非有限/可选纪录、负数与带符号零、共享轨道及重复标识；查询前后源对象一致。
- 已有真实 Worker、跨槽/日切、改签/退役列车回归继续运行；12 游戏小时压力测试生成 6,168、完成 6,044 次出行，守恒通过，12 次重算和 JSON 保存/恢复通过，采样 JS 堆峰值约 24.80 MiB。
- 全量入口：`node scripts/run_rail_tests.cjs`；源产物校验：`node scripts/build_rail_wasm.cjs --check`；发布契约：`node scripts/test_site_publication.cjs`。

## 性能边界

10 线/25 站、30 分钟预热 + 5 × 30 分钟真实 Worker 工作负载，MAP54 和 MAP55 均为 583 次请求、13,068,364 字节输入、11,220,064 字节输出；完整状态哈希均为 `577a48badf49bfbb6c23d5e14fe525965c6679a05e39846a96c3b4d68dea2b11`。本批未减少热循环传输，也未声称提升 FPS。

`benchmark_rail_history55.cjs` 测量同进程交替顺序、每版 200 次预热 + 6 × 1,000 次冷查询，包含编码和对象投影。一次本地样本如下；微秒级数字会受运行环境影响。

| 查询 | MAP54（微秒/次） | MAP55（微秒/次） |
| --- | ---: | ---: |
| 分时视图 | 2.44 | 7.83 |
| 线网长度 | 9.22 | 11.34 |
| 纪录归并 | 1.27 | 2.49 |
| 成就视图 | 2.20 | 4.44 |

独立小查询有编码边界成本。本批优先把规则集中到原生端，为后续批量查询和统一历史状态做准备；这些成本不能用文件迁移数量掩盖。下一步应合并查询或由原生历史状态直接提供摘要，再评估端到端收益。

## 剩余任务

P1-1 仍需把归档与原生统计状态生命周期合并：当前日、完整分时数组和 30 日历史的所有权/快照，滚动小时视图维护、日报聚合及自主跨日接续；目前历史 JSON 对象仍在宿主，`FLOW.touch/record` 和 `ridership.step` 的小时裁剪仍保留，07:00 仍是宿主事务边界。未改写已有成熟度/满意度、事件计数和经营算法。

后续依次为 P1-2 原生改签事务、P1-3 城市生长与设施、P1-4 预测/运行目录整合。P2 的建设、车库和运营诊断规则继续单列。
