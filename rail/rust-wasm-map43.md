# MAP43：完整需求预测迁入 Rust

## 实现范围

接驳采样、步行/骑行/公交候选、站点覆盖、分区归集、枢纽市场激活、游客目的地预算、可达职工/本地外部出行预留、枢纽走廊分配、OD出行分组、原生路径/频率策略缓存、方式选择、分组合并与容量分配统一由 `rust/rail-routing/src/world.rs` 完成。该模块调用既有 Rust 寻路与需求数值核，在内部完成整轮预测。

`demand-model.js` 只保留公共 API 和元数据；`demand-world.js` 负责将城市、线网、枢纽资料编码为数值协议，恢复对象、原有 ID 和城市单元引用。`connection-model.js` 的只读分线总结继续读取最终预测，其预算等公共 API 已变成原生策略的兼容包装。`hubs.js` 保留资料、区域选择和实测口径规范化，分担率由原生核心计算。生产 JS 的采样、枢纽分配和出行分组旧实现已移除，冻结版本仅在 `scripts/fixtures/rail-map42-*.cjs` 供测试使用。

列车/乘客连续模拟、城市生长、满意度、财务、存档及前端继续沿用现有实现。

## 批量边界与所有权

一轮 `evaluate` 调用一次 `forecast_run`。图结构首次使用时由 `graph_load` 装载；每轮独立传入当前票价及最新城市/运营资料。完整预测返回后才替换游戏预测，继续走原来的后台 Worker → 原子接收 → 乘客 rebase 流程。

计数表示需求模型导出函数调用次数，排除缓冲区操作、图装载以及 `Math.exp/log/hypot` 数学原语导入。数学原语继续使用当前 JS 引擎以保留旧版浮点结果；没有回调 JS 的空间、枢纽、寻路或分配模型。

| 原生导出 | 用途 |
| --- | --- |
| `world_abi` | 整段协议版本1 |
| `forecast_run` | 当前票价、城市、站点、枢纽、交路、轨道索引 → 完整预测 |
| `world_run` | 公共 assign / distribution / local / choices API |
| `world_policy` | 公共活动预算、游客预算、行预算、外部预留、枢纽分担率 API |

城市对象使用 WeakMap 身份序号。Rust 最多缓存一个城市的分区和三类 OD 矩阵，城市对象改变即替换；空线网直接返回零预测，不构建 OD 矩阵。寻路组保留24组/60000搜索状态权重上限，频率策略保留1024项，LRU采用哈希查找及有序访问索引，淘汰不扫描整个缓存。淘汰只触发重算，不截断目的地或减少需求。

返回对象、Map与长期矩阵由 JS 独立拥有；临时 WASM 输出投影后释放。内部共享路径用 Rc 管理，分组、缓存和路径在预测退出时释放。超过64MiB的实例在任务完成后重建，最大线性内存256MiB；陷阱后重建实例，已成功预测和已返回对象仍有效。WASM线性内存不写入存档。

## 协议维护

输入头部版本1后依次为城市身份、effective/urban标志、城市版本/步数、分区大小、枢纽参数、五类城市活动总量，以及节点/可用站点/单元/枢纽/交路/轨道/边/原线路数量。各变长记录携带长度；节点与各外部字符串ID通过当次索引恢复。

输出依次为版本/有线路标志/内部搜索次数、总需求与承运汇总、三个活动预算、catchment、枢纽汇总、轨道流量/负荷、分线流量、出行组路径、两类缓存统计。`demand-world.js` 的读指针验证输出边界和完整消费。扩展字段需同步修改编码、Rust解析、输出读取及冻结对照测试；修改布局时升级协议版本和资源文件名，保留旧二进制供缓存页面使用。

## 验证结果

- MAP43新增20个完整预测逐项严格对照和202个空间API对照，覆盖东京/大湾区实际枢纽位置、有效连接/旧模型、成长版本19/36、空线网、停运、环线、直达、边界密度、原生LRU统计、公共策略API、实例重建与异常恢复。
- MAP42继续验证92组矩阵、1200个方式选择、800个频率策略、7个完整预测、容量限流、乘客守恒、存档恢复。
- 轨道项目语法检查及42个回归套件通过。
- 12个模拟小时、12轮预测与JSON存档往返通过；生成6168、完成6044，候车/在途/完成/取消合计守恒。采样JS堆峰值23.19MiB。
- 浏览器从原大湾区测试存档恢复：3线/12站、15列在线；候车301、车上347、累计完成17010保持连续。诊断可查看原生整段预测次数。

## 本机基准

独立 Node 进程、相同确定性输入，预热后取三轮中位数。10线/25站完整预测，另测200分区OD、1200次方式选择、800次策略。MAP42控制组保留原JS接驳、枢纽与分组，使用相同原生数值核；两组结果 SHA256 均为 `ea19bf619a09a213a2411b6a9aa49aa6e2e51462fda9e63c2da96c48c90402b0`。

| 指标 | MAP42混合模型 | MAP43整段原生 |
| --- | ---: | ---: |
| 完整预测中位数 | 820.68ms | 640.06ms |
| 一轮需求模型导出调用 | 23560 | 1 |
| 进程峰值RSS | 234.32MiB | 104.61MiB |
| WASM线性内存 | 3.625MiB | 13.25MiB |

该工作负载完整预测用时下降约22%，进程峰值RSS下降约55%。更多临时数据转入WASM，所以线性内存增加；实际地图与设备会有不同结果。此表不代表整局游戏帧率或浏览器总内存。
