# MAP45：持久队列与有序事件批处理

## 为什么上一版变慢

MAP44只迁移数值决定，JS仍然持有候车、站外和换乘队列。每个模拟步要重新协调两侧状态。10线25站工作负载每60个游戏分钟实测：600次列车推进调用，其中404次需要全量列车同步；另有2166次独立上车调用。编码、复制、查找和事件投影超过了小型算子的节省。

此外，旧64MiB回收阈值与持久队列的常驻工作集冲突，东京旧存档约14个游戏分钟曾触发30次实例回收，反复重建严重拖慢了运行。换乘释放逐条删除中间元素也产生平方级搬移开销。

因此Rust化的收益取决于状态所有权、调用粒度、数据结构和回收策略，而不只是所用语言。需求预测在MAP43已经整段迁移并取得收益，连续模拟则需要单独解决边界开销。

## 当前边界

- `queues.rs`持有有序站台、站外、换乘队列、车厢乘客、占用量，以及累计人数、票款、分线分摊。
- 同一`simulation_step`推进列车及队列，执行进站限流、超时离队、换乘释放、上车、下车、完成出行，返回有序变更批次。
- 删除线路引起的改签使用续处理协议：提交已发生事件，再调用现有Rust寻路接口，随后恢复剩余事件；不重放已下车乘客。
- 列车几何及不变元数据按增量同步。OD抽样缓存分组索引，仍每次读取日需求，兼容运行中的系数修改。
- JS桥接只负责身份映射、快照兼容和展示/统计投影；旧JS连续队列决定已删除。冻结的历史实现在测试目录中用于严格对照。
- 既有存档格式保持兼容；线路重算、交替运行实例、WASM回收或异常恢复后，从当前JS镜像重建原生状态。
- 有序容器维持删除、重新插入的顺序，定期压缩墓碑；数值键使用专用内部哈希。路由/需求计算顺序保持原样。
- 相同路径与分账使用共享不可变存储；票价和目的仍逐个档案保留，改价不会重写已购票。
- Rust换乘队列与JS镜像均使用一次顺序压缩，替代反复删除中间元素，保持同一事件顺序。
- 持久模拟按观察到的工作集自适应回收阈值，软上限192MiB，WASM硬上限仍为256MiB；需求Worker独立实例仍使用64MiB阈值。新游戏/档案替换时先释放旧实例再完整恢复，避免保留旧大工作集。显式强制回收测试不启用自适应。

## 测量

独立Node进程，同一寻路/需求内核，仅替换连续模拟。为减少短测抖动，最终改为预热30个游戏分钟，再测5段120个游戏分钟取中位数；脚本同时输出原始样本。不能把早先3×60分钟的初测数字与此表混用。

| 实现 | 10线25站：120游戏分钟 | 14线49站：120游戏分钟 |
| --- | ---: | ---: |
| MAP43 JS连续模拟 | 249.17ms | 456.98ms |
| MAP44 分段混合模拟 | 329.12ms | 663.55ms |
| MAP45 队列事件批处理 | 266.23ms | 615.29ms |

较MAP44耗时分别下降约19%和7%；相对MAP43纯JS连续模拟，仍分别慢约7%和35%。短测初步结果曾更乐观，最终以延长后的同轮基准为准。整段队列迁移减少了边界往返，但尚未消除原生状态和JS镜像双份更新、逐步事件投影及JS时钟/统计协调的开销。性能结果与原生算法接管程度应分别验收，不以Rust替换数量代替性能收益。

两个规模下三组实现的完整状态、档案及满意度记录校验和均一致：

- 10线：`7493d281e4759cf9dca15d98b3464fb31f4bdd1b0ad69b56748dd1999c58af55`。
- 14线：`6b9c40a4f8096db0e414974d6d68db09d2f3fe9eefd4646c958958219cffa851`。

10线进程RSS：MAP43 119.50MiB、MAP44 159.37MiB、MAP45 162.85MiB；14线分别290.12、301.61、317.11MiB。内存尚未下降；原生运行状态与供UI/存档使用的JS镜像都仍存在。

独立带计数剖析：稳定运行的60分钟共600个队列事件批次，0次队列全量重建，无独立上车调用；队列和列车输入约3.07MB。抽样输入从8.67MB降至2.92MB。计数包装本身有开销，其时间不作为基准。

地图SVG、运营中心DOM、财务结算、满意度反馈与城市时钟仍在JS。后续应把更长模拟区间与统计一并迁入，再改成按展示需要生成快照，以减少双份状态和逐事件投影；这些改动仍需独立对照验收。纯模拟基准不能代表浏览器FPS或浏览器总内存。

## 验证

- 项目语法检查与44个回归套件通过；本机最终整套回归约95.83秒。

- MAP44原有1082个逐步完整状态检查点、1196个抽样对照继续通过。
- MAP45新增450个严格MAP44对照检查点，含小容量拥挤、限流/拒载、整数/加权群体、换乘、票款、删站/删线改签、重算及强制回收，实际覆盖145次改签续处理。
- 18万条共享路径档案超过旧64MiB阈值后连续推进不再回收抖动，新游戏能释放旧大工作集；回收阈值上限也有真实WASM回归断言。
- Rust增加有序队列删除/重插入/压缩和相同路径共享测试，合计11个原生单元测试。
- 12模拟小时、12次重算、12次JSON存档往返：生成6168、完成6044、乘客守恒；采样JS堆峰值23.67MiB。该压力测试进程RSS峰值254.21MiB，包含预测重建与存档工作负载，与上表纯模拟范围不同。
